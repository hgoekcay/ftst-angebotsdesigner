# FTST STRATO Mail · 0.2.0

Eigenständige Home-Assistant-App für ein STRATO-Postfach. Vorgesehen für amd64.
Der Dienst bietet lesenden Mailzugriff, eine lokale Verbindungsüberwachung und einen
OAuth-geschützten MCP-Endpunkt. Er nutzt Port 8098 und seinen eigenen `/data`-Ordner.

Die App befindet sich in der Erprobung. Das echte Postfach, Home Assistant und der
Cloudflare-Zugang müssen nach der Installation geprüft werden.

Die vollständigen Anleitungen stehen im Paket: `INSTALLATION-DE.md` und
`BETRIEB-DE.md`. Die App-Dokumentation enthält die wichtigsten Einstellungen.
